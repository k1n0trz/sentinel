# Sentinel Product Spec

Sentinel is a defensive cybersecurity agent for web, SaaS, ecommerce, API, WordPress, and custom application surfaces.

## Promise

Detect risks before they become incidents.

## Brand

- Name: Sentinel
- Phrase: Vigilant. Intelligent. Unseen.
- Spanish variant: Vigila. Aprende. Protege.
- Visual direction: dark, premium, minimal, vigilant, technical
- Primary visual metaphor: eye, lens, or radar

## Target Customers

- Digital agencies
- SaaS startups
- Ecommerce teams
- WordPress and WooCommerce sites
- Companies with public APIs
- Businesses that sell online
- k1n0 clients buying apps, landing pages, CRM, CMS, or custom systems

## MVP Scope

The first product stage provides a passive or low-impact public diagnostic:

- URL normalization
- HTTP status and final URL
- HTTPS detection
- Security headers review
- Basic SSL certificate metadata
- Basic DNS resolution
- Initial 0-100 risk score
- Severity-ranked findings
- Dashboard report

Advanced scans require domain ownership verification and explicit authorization.

## Future Modules

- Subdomain discovery
- Technology fingerprinting
- Frontend risk analyzer
- API exposure scanner
- Visual sandbox tester with Playwright
- WordPress and WooCommerce Guardian
- Repository scanner
- AI security analyst
- Continuous monitoring
- Alerting and billing
