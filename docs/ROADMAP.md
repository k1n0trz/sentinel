# Sentinel Roadmap

## Phase 0: Repository Foundation

- Monorepo
- Frontend app
- Backend API
- Shared package
- Prisma schema
- Docker Compose
- Environment example
- CI
- Initial documentation

## Phase 1: MVP Passive Scanner

- Free scan endpoint
- Security headers scanner
- SSL scanner
- DNS scanner
- Scoring engine
- Result dashboard
- Structured report endpoint
- Local scan history

## Phase 2: SaaS Dashboard and Persistence

- Authentication
- Users
- Projects
- Domains
- Domain verification
- Persistent scans and reports
- Basic admin panel

## Phase 3: Visual Sandbox

- Playwright browser isolation
- Screenshot evidence
- Console logs
- Failed requests
- Cookies and storage review
- Mixed content detection

## Phase 4: Surface Expansion

- Passive subdomain discovery
- API route scanner
- Technology fingerprinting
- Robots.txt and sitemap.xml review
- Public file checks

## Phase 5: Continuous Monitoring

- BullMQ jobs
- Manual, daily, weekly, and monthly scans
- Score change alerts
- SSL expiration alerts
- Header removal alerts
- DNS change alerts

## Phase 6+: Commercial Growth

- WordPress and WooCommerce Guardian
- AI analyst
- GitHub integration
- Billing and plan limits
- Assisted hardening snippets and pull requests
